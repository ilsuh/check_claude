# Формы слов по словарю Зализняка

Простая программа: вводите русское слово — получаете все его формы
(падежи, числа, роды, времена, лица, причастия и т. д.) с ударениями.

Данные — файлы `data/zaliz_1.yml` и `data/zaliz_2.yml` из проекта
[jurta/nlp-rus-zaliz](https://github.com/jurta/nlp-rus-zaliz)
(полные парадигмы «Грамматического словаря русского языка» А. А. Зализняка,
~93 000 лемм; распространяются по лицензии GNU GPL). Программа разбирает их
в соответствии с разделом «Описание формата YAML» README того репозитория:

* `о`, `о1` … `о5` — основы слова, `п` — парадигма: словоформы через `;`,
  варианты через `,`, число в начале окончания — номер основы;
* порядок словоформ в `п` для каждой части речи взят из
  `Lingua/RU/Zaliz/Inflect.pm` (`%paradigms`);
* пометы при окончаниях (из `adb2yml.pl`): `-` — формы нет, `*` — форма
  затруднительна, `?` — предположительна, `[в]`/`[на]` — 2-й предложный
  падеж, `[]` — 2-й родительный, `(...)` — комментарий.

## Запуск

Нужен только Python 3 (без сторонних библиотек).

```sh
python3 zaliz.py стол идти       # формы указанных слов
python3 zaliz.py                 # интерактивный режим
python3 zaliz.py --plain хороший # без знаков ударения
```

Можно вводить и любую словоформу: `python3 zaliz.py шёл` найдёт глагол
«идти» и покажет все его формы. Буквы «е» и «ё» при поиске не различаются.

Пример:

```
$ python3 zaliz.py лес
...
Значение 1:
  [существительное, мужской род, тип 1c]
  Значение/помета: растущий

                 ед. ч.         мн. ч.
  Именительный   ле́с            леса́
  Родительный    ле́са           лесо́в
  Дательный      ле́су           леса́м
  Винительный    ле́с            леса́
  Творительный   ле́сом          леса́ми
  Предложный     ле́се, в лесу́   леса́х
```
